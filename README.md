# 線上學習系統（buke-app）

影片分段＋段落檢核。看完一段、答對題目才解鎖下一段；名單分區匯入，學習記錄依區域匯出。

- 前端：Vite + React 18 + TypeScript
- 影片：YouTube 內嵌（公開或不公開）
- 資料庫：Firebase Firestore（不使用 Firebase Auth）
- 網站：<https://krad1985.github.io/buke-app/>
- 字體：Noto Serif TC／Noto Sans TC（Google Fonts，SIL Open Font License）

## 身分

| 身分 | 登入 | 範圍 |
| --- | --- | --- |
| 學員 | 學員代碼或手機 | 上課、看自己的進度 |
| 課程管理員 | 帳號 `admin` + 密碼 | 全部課程、全部區域、管理帳號 |
| 區域管理員 | 自己的帳號 + 密碼 | 只有自己區域的名單與記錄 |

學員登入一次後會記在這台裝置（localStorage），下次直接進課程；要換人按右上角「換人」。

課程管理員預設帳號 `admin`、密碼 `admin`，登入後到「我的密碼」改掉。

## 規則

不需要再貼。目前資料庫用到的集合（`courses`、`admins`、`phones`、`regions`…）都在已發布的規則允許範圍內。

若日後想簡化，`firestore.rules` 是一行全開版本，貼上去也能運作（但就沒有 `phones` 不可列舉的差別）。

## 開發

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run deploy   # 推到 gh-pages
```

路由：`/` 學員首頁、`/#/c/<courseId>` 上課、`/#/admin` 後台。
QA：網址加 `?qa=1` 會多一顆「跳結尾」。

## 資料結構

```
courses/{courseId}                                      課程（含段落與題目）
admins/{帳號}                                           管理員（含密碼、角色、區域）
phones/{學員代碼或手機}                                  登入索引 → 區域
regions/{區域}/students/{學員代碼}                      學員名單
regions/{區域}/students/{學員代碼}/progress/{courseId}  補課進度
```

進度以學員代碼為 key，換裝置也還在。

## 匯入名單

「學員名單」頁選區域 → 選檔或拖曳（xlsx / csv），也可以貼上。按「下載範本」可取得空白 CSV：

```
學員代碼, 學員姓名, 母班行政組織, 大組, 小組, 身份別, 手機
```

系統匯出的「學員名單查詢結果」xlsx 可直接上傳，欄位對應：

| 匯出檔欄位 | 系統欄位 |
| --- | --- |
| 學員代碼 | 學員代碼（文件 ID、登入用） |
| 學員姓名 | 姓名 |
| 母班行政組織 | 母班 |
| 大組 + 小組 | 組別（`1-1`） |
| 身份別 | 身份 |
| （自行新增）手機 | 手機（登入用，選填） |

其餘欄位（出席率、善行完成率…）忽略。手機格式不對會提示並略過該欄，不影響匯入。同代碼重匯＝覆蓋。

## 匯出補課記錄

一人一列、各課程一欄：

```
區域, 學員代碼, 母班, 組別, 身份, 姓名,
<課程A>, <課程B>, …, 完課數, 已補時數(分), 最後更新
```

`✓` 完課、`3/5` 已通過 3 段、空白表示沒紀錄。可勾「只列有紀錄的學員」。

區域管理員只能讀自己區域；課程管理員可切換區域。

## 補課時數

已通過段落的影片長度加總（重看、暫停不重複累計）。段落時間碼日後調整，已記錄的時數不會回溯。

## 播放器

- `controls=0` 關掉 YouTube 原生控制列
- 全尺寸透明遮罩攔掉所有點擊（標題、Logo、「在 YouTube 觀看」都點不到）
- 自訂控制列：播放/暫停、段落內時間軸、倍速、全螢幕、重看本段
- 全螢幕只包播放器與控制列；進入答題時自動退出

時間軸刻意限制在「目前段落」範圍，這是分段解鎖的核心。

> 遮蔽 YouTube 品牌與外連有違反其服務條款的風險，由使用者承擔；官方改版可能讓 `controls=0` 的行為改變。

## 安全模型（請務必了解）

- 沒有伺服器端驗證。規則開放，任何人開 devtools 都能讀寫、也能讀到管理員密碼。
- 管理密碼與區域管理員密碼都只是畫面上的門；知道別人密碼就能切到別區（已知且接受）。
- 分區是為了操作方便，不是權限隔離。

既有緩解：課程管理頁有**匯出備份／匯入備份**（JSON）。

## 已知限制

1. 報表逐位學員讀取，一區數百人會慢一些。
2. 影片要「只聽不看」需自架 HLS，YouTube 做不到。
3. 同一位學員的多支手機只會索引匯入時填的那一支。

`src/data/mockCourses.ts` 只是「載入示範課程」的種子資料。
