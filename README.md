# 線上學習系統（buke-app）

影片分段＋段落檢核。看完一段、答對題目才解鎖下一段；名單分區匯入，學習記錄依區域匯出。

- 前端：Vite + React 18 + TypeScript
- 影片：YouTube 內嵌（公開或不公開）
- 資料庫：Firebase Firestore（不使用 Firebase Auth）
- 網站：<https://krad1985.github.io/buke-app/>

## 角色

| 角色 | 登入 | 能做什麼 |
| --- | --- | --- |
| 學員 | 學員代碼或手機 | 上課、看自己的進度與同組進度 |
| 總管理員 | 帳號密碼 | 全部功能：系列、課程、名單、記錄、管理員、設定 |
| 系列管理員 | 帳號密碼 | 只管理被指派的系列課程（上架、題庫） |
| 區域窗口 | 帳號密碼 | 管理自己區域的名單、記錄；可建立教室窗口 |
| 教室窗口 | 帳號密碼 | 管理自己教室的名單、記錄 |

預設總管理員：帳號 `admin`、密碼 `admin`，登入後請改。

## 系列課程

- 「系列」頁建立系列（例如：奢摩他儲、毗缽舍那…）。
- 課程編輯時指定系列；**未指定系列的課程所有學員都看得到**（相容舊資料）。
- 匯入名單時可選擇「加入系列」，會累加到學員的系列清單，**同一位學員可同時屬於多個系列**，就看得到多個系列的課。
- 學員登入後只看得到自己系列 ＋ 未分類的課程。

## 名單匯入

「學員名單」頁：選區域（總管理員）→ 選系列（可略）→ 上傳 xlsx／csv 或貼上。

範本欄位：

```
學員代碼, 學員姓名, 母班行政組織, 大組, 小組, 身份別, 手機
```

- 系統匯出的「學員名單查詢結果」可直接上傳；多出來的欄位會忽略。
- 大組與小組分成兩欄儲存，不再合併。
- 手機可用於登入；格式不對會提示並略過該欄。
- 同一支代碼重複匯入＝覆蓋基本資料，系列採累加。
- 教室窗口匯入時，教室固定為自己教室。

匯入前會顯示前 3 筆預覽；匯入後可逐筆編輯（含手機）或勾選批次刪除。

## 學習記錄匯出

一人一列、各課程一欄：

```
區域, 學員代碼, 母班, 大組, 小組, 身份, 姓名,
<課程A>, <課程B>, …, 完課數, 已學習時數(分), 最後更新
```

`✓` 完課、`3/5` 已通過 3 段。教室窗口只會看到自己教室的學員。

## 同組進度

學員登入後，課程頁右上角「同組進度」可看同區域、同大組、同小組的同學在同一門課的進度。

## 設定

「設定」頁可關閉「訪客瀏覽」。關閉後，未登入只能看到登入頁，不能瀏覽課程。

## 資料結構

```
series/{seriesId}                                       系列
courses/{courseId}                                      課程（含 seriesId）
config/settings                                         系統設定
admins/{帳號}                                           管理員（角色、區域、教室、系列、密碼）
phones/{學員代碼或手機}                                  登入索引
regions/{區域}/students/{學員代碼}                      名單（含 groupLarge、groupSmall、seriesIds）
regions/{區域}/students/{學員代碼}/progress/{courseId}  學習進度
```

## 規則

`firestore.rules` 是一行全開版本。**這次新增了 `series` 與 `config` 兩個集合，需要重新貼一次**（貼完之後新增集合都不用再改）：

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} { allow read, write: if true; }
  }
}
```

## 開發

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run deploy
```

路由：`/`、`/#/c/<courseId>`、`/#/admin`。QA：加 `?qa=1` 會多「跳結尾」。

## 安全模型

- 沒有伺服器端驗證，規則全開；能開網站的人都可以用 devtools 讀寫。
- 角色與範圍只是畫面層的區分，不是權限隔離。
- 既有緩解：課程可匯出／匯入備份（JSON）。

## 已知限制

1. 同一位學員多支手機只索引匯入時那一支。
2. 報表逐位學員讀取，一區數百人會慢一些。
3. 影片要「只聽不看」需自架 HLS。

`src/data/mockCourses.ts` 只是「載入示範課程」的種子資料。
